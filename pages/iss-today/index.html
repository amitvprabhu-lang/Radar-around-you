How this page is made

  • Positions are computed, not observed: CelesTrak's element set for the ISS (NORAD catalogue number 25544) is run through the SGP4 model with the satellite.js library, the same code as the live app. We have not measured how far these positions drift from the real ISS as the element set ages; the age is shown above.
  • This page is a snapshot at the data time. The real-time view is the live globe.
  • The live copy of this page is published only when the satellite data is less than 30 hours old and the ISS element set less than 7 days old. A copy built when the site is deployed uses the data bundled with the site, which can be older than that; it then says so at the top, and the live copy replaces it after the next data collection.

Questions

Where is the ISS right now?

This page gives its position at the data time, 11 October 2026, 02:30 UTC: 30.4° S, 1.5° E. It moves about 3.9 degrees around the Earth every minute, so for where it is now, open the live globe, which computes it in your browser.

How high is the ISS?

Between 419 and 434 km over the orbit after the data time, 427 km on average, computed from the element set.

How long does the ISS take to go round the Earth?

93.0 minutes, from the element set's 15.49 orbits a day.

When can I see the ISS?

When it passes over you while it is in sunlight and your sky is dark. 3 of the 23 passes over the six cities in the 24 hours after the data time are like that; the tables give the times.

Radar Around You is a free tool for looking up: what is overhead, what is in tonight's sky and what the ground has just done. Satellite and quake data come from CelesTrak and the USGS. Positions of the Moon, Sun and planets are computed with the astronomy-engine library. Every number on these pages links to how it was found on How we know.
