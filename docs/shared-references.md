# Repositories shared for ideas

Read on 2026-10-04 (shallow clones, read only). These are notes on what each one is and what, if anything, was taken from it.
No code was copied from any of them.

| Repository | What it is | Taken from it |
|---|---|---|
| bilawalsidhu/gods-eye-view | A 3D globe with many live layers. MIT code. Its `DATA_SOURCES.md` lists every source with its licence, separates code licence from data licence, and shows attribution in the app. | The practice of stating a licence per source and crediting in the app (the Data status sheet does this). Its list names NASA GIBS (public domain, browser-direct per its file), The Space Devs Launch Library 2, NOAA GFS on AWS Open Data and NHC advisories as sources. These are that project's statements and need checking against each source's own page before use here. |
| eleanorlutz/asteroids_atlas_of_space | A tutorial for mapping the solar system from NASA JPL Small-Body Database queries, NASA PDS data and JPL HORIZONS. GPL v3. | The idea of a solar system and asteroid view built from JPL Small-Body Database data. The code is GPL v3 and this project is MIT, so nothing is reused. |
| openai/openai-realtime-solar-system | A voice-controlled 3D solar system using the OpenAI Realtime API and Spline. MIT. | The idea of asking the sky questions by voice. It needs a paid API key and a server, so it does not fit a free site with no backend. Not planned. |
| udacity/ud843-QuakeReport | An Android tutorial that lists recent earthquakes from the USGS event query API (`earthquake.usgs.gov/fdsnws/event/1/`). | That API supports filtered and historical queries, which suits "earthquakes near you" and a quake history. Not yet used. |
| satellite-image-deep-learning/techniques | A reading list of deep learning techniques for satellite imagery. | Nothing for this app, which does not process imagery. |
| h9zdev/GeoSentinel | A surveillance and OSINT platform (people search, dark web search, camera feeds). | Nothing. Not appropriate to build on. |
| jugyo/earthquake | A Ruby command line Twitter client, unrelated to earthquake data. | Nothing. |
